# 0113357 Bahasa Melayu untuk Perhotelan

เว็บไซต์รายวิชา **0113357 ภาษามลายูเพื่อการโรงแรม** (Malay for Hotel Business)
หลักสูตรภาษามลายู คณะมนุษยศาสตร์และสังคมศาสตร์ มหาวิทยาลัยทักษิณ ภาคเรียนที่ 2/2569

ผู้สอน: อ.ดร.กูซม ยามิรูเด็ง

## เนื้อหา

- `index.html` หน้าแรก: ข้อมูลรายวิชา CLOs กำหนดการ การวัดผล และรายการบท
- `bab-01.html` ถึง `bab-12.html` บทเรียน 12 บท (ภาษามลายูอยู่บน ภาษาไทยอยู่ล่าง)
- `pdf/` ไฟล์ PDF ของแต่ละบทสำหรับนิสิตดาวน์โหลด
- `assets/style.css` รูปแบบหน้าเว็บ

เว็บนี้เป็นฉบับสำหรับนิสิต ไม่มีตารางกิจกรรมและแบบสังเกตของผู้สอน
เฉลยแบบฝึกหัดจะเปิดทีละบทหลังจากเรียนบทนั้นในชั้นเรียนแล้ว
